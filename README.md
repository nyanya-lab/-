# 우리 실천 보드

둘이 같이 쓰는 계획·실천 웹앱 (`planner/index.html`).

- **오늘**: 오늘 할 일 체크, 매일 습관, 실천 기록(분·메모), 서로 응원하기
- **목표**: 자격증 목표와 D-day, 진행률, 추천 꾸러미(전산응용건축제도기능사·실내건축기능사·타일기능사·현장)
- **기록**: 최근 12주 '타일 벽'(하루 한 장, 대각선 반쪽씩 두 사람), 이번 주 통계
- **돈**: 월급·수입, 보낸 돈, 생활비 가계부(분류별 지출·예산), 월별 남은 돈
- **구글 캘린더**: 할 일·목표 옆 '캘린더' 버튼으로 일정 추가 (매일 습관은 반복 일정)

공유 버전(둘이 같은 데이터를 실시간으로 봄): claude.ai 아티팩트로 배포되어 있음.
이 파일을 그냥 브라우저로 열면 그 기기에만 저장되는 모드로 동작함.
