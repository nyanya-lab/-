욱진 실천 보드

구글 캘린더 자동 동기화 설정

욱진이 구글 계정에서 딱 한 번만 하면 돼요. 그 뒤로는 5분마다 알아서 보드 할 일·시험일이 구글 캘린더에 들어가고, 구글 일정도 보드 달력에 보여요. 사이트에서 구글 로그인은 필요 없어요. PC에서 하는 걸 추천해요 (10분 정도).

  1. Apps Script 열기

    욱진이 구글 계정으로 로그인한 상태에서 script.google.com 새 프로젝트를 열어요.

    구글 계정이 여러 개면 오른쪽 위 동그라미 사진이 욱진이 계정인지 꼭 확인해요.

  2. 프로젝트 이름 바꾸기

    왼쪽 위 제목 없는 프로젝트를 눌러 욱진 실천 보드 동기화로 바꿔요.

  3. 코드 붙여넣기

    가운데 편집기에 있는 function myFunction() { … }을 전부 지우고, 아래 코드를 코드 복사로 복사해서 붙여넣어요.

    불러오는 중…

  4. 보드 비밀번호 넣고 저장

    코드 위쪽 const BOARD_PASSWORD = "";의 따옴표 사이에 보드 비밀번호를 넣어요. 예: const BOARD_PASSWORD = "비밀번호";

    그다음 저장(디스크 아이콘, 또는 Ctrl + S)을 눌러요.

    이 코드는 욱진이 구글 계정 안에만 있어서 다른 사람은 못 봐요.

  5. Google Calendar API 추가

    왼쪽 메뉴 서비스 옆 +를 누르고, 목록에서 Google Calendar API를 골라 추가를 눌러요.

  6. setup 실행하고 권한 허락

    • 편집기 위쪽 함수 고르는 칸에서 setup을 고르고 ▶ 실행을 눌러요.
    • 권한 검토 → 욱진이 계정 선택.
    • "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → 욱진 실천 보드 동기화(으)로 이동(안전하지 않음)을 눌러요. 욱진이가 직접 만든 스크립트라서 나오는 화면이에요.
    • 허용을 눌러요.

  7. 끝! 확인하기

    아래 실행 로그에 설정 끝! 이제 5분마다 자동으로 맞춰요.가 나오면 성공이에요.

    보드 사이트 ⚙ 설정 → 구글 캘린더에 "자동 동기화 중"이 보이고, 달력 위에 구글 동기화 시간이 떠요.

보드에서 할 일을 추가·체크·삭제하면 5분 안에 구글 캘린더에 반영돼요. 구글 캘린더에는 이렇게 보여요:
  • (예) 할 일 · 파랑 = 아직 안 한 할 일
  • (완) 할 일 · 초록 = 끝낸 할 일 (반복하는 일은 한 날 칸만 초록)
  • (반복) 할 일 · 보라 = 매일·매주 반복하는 일 (반복 일정 하나로 들어가요)
  • [D-DAY] 목표 · 빨강 = 시험일·목표일
예전에 할 일 옆 '캘린더' 버튼으로 직접 넣었던 보드 일정은 첫 동기화 때 같이 정리돼요.

문제 해결

"BOARD_PASSWORD에 보드 비밀번호를 넣고…"4번에서 비밀번호를 넣고 저장했는지 확인해요.
"이 비밀번호로 만든 보드가 없어요"비밀번호에 오타가 있어요. 사이트에서 쓰는 비밀번호와 똑같이 넣어요.
"Calendar is not defined"5번(서비스에 Google Calendar API 추가)이 빠졌어요.
사이트에 "구글 동기화 멈춤"이 떠요Apps Script 왼쪽 트리거(시계 아이콘)에 sync가 있는지 봐요. 없으면 setup을 다시 실행해요. 실행 메뉴(목록 아이콘)에서 빨간 실패 기록을 누르면 이유가 보여요.
보드 비밀번호를 바꿨어요4번처럼 새 비밀번호로 고치고 저장하면 다음 5분부터 새 보드로 맞춰요.
그만 쓰고 싶어요함수 칸에서 stop을 골라 실행하면 자동 동기화가 멈춰요.
